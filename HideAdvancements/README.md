# Description

This script hides all advancements in chat.

# Setup

- Download and install the script to your avatar
- Go into Figura settings then search for and activate "Chat Messages"

# Important

**By enabling Chat Messages, you give scripts permission to modify incoming and outgoing chat.**

Make sure you are familiar with all scripts that you are installing. If you are unsure, go to your nearest Figura expert or join our Discord linked in Figura's help tab!
