# Description

This script allows you to render the backpack model on your avatar if you hide vanilla_model armor. It is intended to fix issues where showing the vanilla_model chestplate while wearing a backpack can sometimes cause the backpack to render in a weird position.

# Setup

- Download and install the script to your avatar
