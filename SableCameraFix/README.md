# Description

If you plan on using [Jeceratops/Ferrets-Figura-Functions](https://github.com/Jeceratops/Ferrets-Figura-Functions) or [KingRoboLizard/figura-aero-addon](https://github.com/KingRoboLizard/figura-aero-addon) then this fix is not for you. This script fixes the camera rotation when sitting in simulated contraptions in vanilla Figura.

# Setup

- Download and install the script to your avatar

# Important

This script may misbehave if you are using another script that modifies the camera.
