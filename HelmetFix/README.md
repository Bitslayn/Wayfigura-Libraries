# Description

This script allows you to render modded helmet armors on your avatar. It is intended to fix the issue where modded armors show a glitched texture rather than the custom armor model.

# Setup

- Download and install the script to your avatar
- Make sure you have either a helmet item pivot or a helmet pivot in your head
